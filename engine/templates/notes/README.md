# Study notebooks

One detailed notebook per topic, filed by phase — `phase-N-name/topic-NN-name.md`, names spelled
exactly as `MISSION.md`'s baseline table. This folder is the lasting reference; `progress.md`
records each session, the notebooks *teach you again in six months*.

Built up day by day, a notebook holds the full explanations, the commands actually run, the real
output, and the troubleshooting as it happened — including the dead ends. Conventions the
protocol enforces:

- **Syntax before example.** Every command shows its general syntax pattern first, then the
  concrete invocation that was actually run.
- **Verify before recording.** Every claimed discovery, rule, or formula is technically verified
  before it is written down. A wrong rule recorded confidently is worse than no rule at all.
- **Redact on capture.** Usernames, emails and anything `MISSION.md` marks private are replaced
  with its placeholders at the moment output is pasted — not in a cleanup pass later.
- **The quiz block ends the topic**, question by question as it was actually asked, closing with
  `**Verdict**: **Topic N CLEARED, attempt N, XX/100.**`
