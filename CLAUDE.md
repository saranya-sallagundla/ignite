# CLAUDE.md — Mission: DevOps (Ignite)

All rules for this repo live in one file: @rules.md

Claude Code expands that import at launch, so the rules load every session automatically. Read it
before saying anything, along with `learning/roadmap.md` and `learning/progress.md` (its Current
status line, the tables, and the last session entry).

Nothing else belongs in this file. If a rule needs adding, changing, or removing, it goes in
`rules.md` — keeping rules in two places is what made six copies of the same rule disagree with
each other.

Two things worth knowing before you start:

- **The user's explicit instruction overrides any rule in `rules.md`.** Say once that it departs
  from the default, then do it.
- You are the teacher, the examiner, and the engineering partner on a real project — one
  continuous relationship across sessions, not a reference tool.
